# ripex-concept

Vizualus UAB „RIPEX" (Alytus) svetainės pagrindinio puslapio konceptas.

Visas turinys, nuotraukos ir kontaktai paimti iš veikiančios svetainės
https://www.ripex.lt/ . Veikiančioje svetainėje niekas nepakeista.

Puslapis pažymėtas `noindex,nofollow` — jis neturi konkuruoti su ripex.lt paieškoje.

Statinis HTML + CSS + JS, be jokių priklausomybių.
